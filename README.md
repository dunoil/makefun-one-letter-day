A make.fun entry for the "One Letter for Your Day" bounty ($5 prize). The program writes exactly one letter, A to Z, standing for the word that describes the day, to `/output/entry.txt`.

Entry letter (1 character):

> Q

## How to run

```sh
node main.ts
```

By default it writes to `/output/entry.txt`. Set `OUTPUT_PATH` to write elsewhere, for example `OUTPUT_PATH=/tmp/one-letter-out/entry.txt node main.ts`.
